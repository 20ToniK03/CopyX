# CopyX

Rust-only MVP ShareX-подобного инструмента для Windows.

## Скачать

Готовый `CopyX-0.1.1.exe` — в разделе [Releases](https://github.com/20ToniK03/CopyX/releases/latest). Установка не требуется, Windows 10/11 x64.

## Запуск EXE

Готовый файл находится здесь:

`target\release\CopyX.exe`

## Иконка

`app.svg` → `app.ico` (16, 20, 24, 32, 40, 48, 64, 128, 256 px) → встраивается в EXE
через `app.rc` и `build.rs` (используется `rc.exe` из Windows SDK). Та же иконка
показывается в системном трее.

## Запуск из Cargo

```text
cargo run -- full
cargo run -- all
cargo run -- region 0 0 800 600
```

После каждого скриншота изображение сразу копируется в буфер обмена. В правом нижнем углу появляется стеклянное уведомление с миниатюрой и кнопками «Скрыть» / «Сохранить»; без действий оно само скрывается через 3 секунды. При запуске приложения такое же уведомление показывает горячие клавиши.

## Горячие клавиши

- `PrtSc` — выделение области (внутри: `Ctrl+A` — весь экран, `Esc` — отмена)
- `Ctrl+PrtSc` — активное окно
- `Shift+PrtSc` — весь экран
- `Ctrl+Shift+S` — резервная комбинация для выделения области

## Автозапуск

В меню трея есть пункт **«Запускать при старте Windows»** с галочкой. Он добавляет
или удаляет значение `CopyX` в ветке
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` — права администратора не
нужны, запись видна и отключается в «Диспетчере задач → Автозагрузка».

При включении сохраняется путь к текущему EXE, поэтому после переноса папки с
программой автозапуск нужно включить заново. Второй экземпляр CopyX не
запускается: вместо двух иконок в трее появляется сообщение, что программа уже
работает.
