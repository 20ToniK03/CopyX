# CopyX

Rust-only MVP ShareX-подобного инструмента для Windows.

## Скачать

Готовый `CopyX-0.2.1.exe` — в разделе [Releases](https://github.com/20ToniK03/CopyX/releases/latest). Установка не требуется, Windows 10/11 x64.

## Запуск EXE

Готовый файл находится здесь:

`target\release\CopyX.exe`

## Иконка

`app.svg` → `app.ico` (16, 20, 24, 32, 40, 48, 64, 128, 256 px) → встраивается в EXE
через `app.rc` и `build.rs` (используется `rc.exe` из Windows SDK). Та же иконка
показывается в системном трее.

## Запуск из Cargo

```text
cargo run -- full
cargo run -- all
cargo run -- region 0 0 800 600
```

После каждого скриншота изображение сразу копируется в буфер обмена. В правом нижнем углу появляется стеклянное уведомление с миниатюрой и кнопками «Скрыть» / «Сохранить»; без действий оно само скрывается через 3 секунды. При запуске приложения такое же уведомление показывает горячие клавиши.

Карточка уведомления тоже собирается в отдельный буфер и выводится одним кадром, а при наведении перерисовываются только кнопки — поэтому текст, миниатюра и сама карточка не дёргаются. Над кнопками курсор становится «рукой».

## Горячие клавиши

- `PrtSc` — выделение области; рамка остаётся на экране, чтобы добавить аннотации
  (`Ctrl+A` — весь экран, `Enter` — скопировать, `Esc` — отмена)
- `Ctrl+PrtSc` — активное окно
- `Shift+PrtSc` — весь экран
- `Ctrl+Shift+S` — резервная комбинация для выделения области

## Редактор снимков

После `PrtSc` оверлей показывает только подсказку и подсветку окна под курсором.
Панель инструментов появляется **после того, как область уже выделена**: пока вы
тянете рамку, она не мешает и не прыгает под курсором.

По умолчанию выбран **«Область»**, поэтому первым действием всегда можно просто
выделить нужный участок. Рамка остаётся на экране — поверх неё добавляются
аннотации. Панель и кнопки — матовое стекло с размытием, бликом и тонкой светлой
кромкой; активный инструмент подсвечивается цветным свечением, а у рамки
выделения есть белые «уголки».

Инструменты:

- **Область** — новое выделение (клик без перетаскивания выбирает окно под курсором).
- **Пиксели** — мозаика: усредняет цвета квадратными блоками.
- **Размытие** — гауссово размытие выбранного участка.
- **Стрелка**, **Линия**, **Квадрат**, **Круг** — красные аннотации.

Порядок работы:

1. Выделите область мышью — панель появится под рамкой.
2. Выберите инструмент на панели или клавишами `1`–`7`.
3. Протяните мышь внутри области — аннотация появится сразу; для «Пикселей» и
   «Размытия» во время перетаскивания показывается живое превью.
4. Нажмите `Enter`, `Ctrl+C` или кнопку **«Копировать»**.

### Ровные фигуры, перемещение и поворот

- Удерживайте `Shift` во время рисования: квадрат и круг получаются правильными,
  а линия и стрелка притягиваются к углам **0°, 45°, 90°, 135°, 180°**.
- Свежая фигура сразу выделена: над ней видна круглая ручка поворота. Тяните
  ручку — фигура вращается вокруг своего центра. С `Shift` поворот идёт шагом
  **15°**.
- Выделенную фигуру можно перетаскивать: зажмите кнопку мыши на её теле и ведите
  в сторону. Это работает сразу после рисования и для фигуры, выбранной
  инструментом **«Область»**, при любом активном инструменте; курсор над телом
  становится «четырёхстрелочным».
- Чтобы выбрать уже нарисованную фигуру, инструментом **«Область»** кликните по
  её контуру (не внутри) — появится пунктирная рамка с ручкой. Ручка поворота
  приоритетнее перемещения, поэтому фигуру удобно сначала вращать, а затем
  двигать.
- `Delete` / `Backspace` удаляет выделенную фигуру, `Esc` снимает выделение,
  повторный `Esc` закрывает оверлей.
- Перемещение и поворот сохраняются и в буфере обмена, и в сохранённом PNG;
  фигура при перетаскивании не выходит за пределы выделения.

Горячие клавиши редактора:

- `1`–`7` — инструменты (можно и с `Ctrl`); до выделения области не действуют;
- `Shift` — ровная фигура/линия при рисовании и шаг 15° при повороте;
- перетаскивание тела выделенной фигуры — перемещение по области;
- `Delete` / `Backspace` — удалить выделенную фигуру;
- `Ctrl+Z` — отменить последнюю аннотацию;
- `Ctrl+A` — выделить весь экран;
- `Enter` / `Ctrl+C` / **«Копировать»** — скопировать снимок с аннотациями;
- `Esc` — снять выделение с фигуры, повторно — закрыть оверлей без снимка;
  правая кнопка мыши закрывает сразу.

Аннотации не выходят за пределы выделения, а в буфер обмена и на сохранённый PNG
попадает уже готовое изображение с эффектами и фигурами. Оверлей рисуется в
отдельный буфер и выводится на экран одним кадром, поэтому при движении мыши
нет мерцания.

## Автозапуск

В меню трея есть пункт **«Запускать при старте Windows»** с галочкой. Он добавляет
или удаляет значение `CopyX` в ветке
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` — права администратора не
нужны, запись видна и отключается в «Диспетчере задач → Автозагрузка».

При включении сохраняется путь к текущему EXE, поэтому после переноса папки с
программой автозапуск нужно включить заново. Второй экземпляр CopyX не
запускается: вместо двух иконок в трее появляется сообщение, что программа уже
работает.
